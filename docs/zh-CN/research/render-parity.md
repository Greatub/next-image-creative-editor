# 渲染一致性：LibRaw 与 NX Studio 对比 —— 研究记录

最后更新：2026-10-23

[English](../../research/render-parity.md) | [简体中文](render-parity.md)

状态：**研究记录**，不是规范。涉及 Q-016，并为 Q-001、Q-004 和「NX Studio 可还原」的措辞提供依据。

## 1. 问题

`.nksc` 研究（见 [nksc-format.md](nksc-format.md)）证明 NX Studio 能*读取* NICE 写入的参数。本文研究另一个问题：如果 NICE 用开源解码器渲染同一张 NEF，结果和 NX Studio 有多接近？差距来自哪里？

## 2. 样本与方法

- 与 `.nksc` 研究使用同一张 NEF：尼康 Z 30，NIKKOR Z DX 12-28mm f/3.5-5.6 PZ VR，12mm 端，`DSC_3183`。
- 标准答案：NX Studio 1.11（macOS）导出的 JPEG。样本 **e**（未编辑，优化校准为自动）和样本 **a**（曝光 +1.0 EV）。两者都标记为「Nikon sRGB 4.0.0.3002」，尺寸 5568×3712。
- 尼康自家的参照：机内 JPEG `DSC_3183.JPG`，以及 NEF 内嵌的全尺寸预览 JPEG。
- 代表 NICE 的渲染：LibRaw 0.22（rawpy），设置如下：
  - 相机白平衡
  - sRGB 原色
  - 线性输出
  - 不自动提亮
  - 半尺寸解码
- 统一在 2784×1856、线性光下比较。指标为 **CIEDE2000（ΔE）**，给出平均值 / 第 95 百分位。
  - 粗略参考：小于 1 看不出；1–2 并排才看得出；大于 5 明显不同。
- 逐步重建处理流程，看每一步各解释了多少差距：
  - 几何：SIFT 特征匹配后拟合径向模型。3362 个内点，中位残差 0.22 像素。
  - 暗角：按半径的增益。
  - 色调：单调的亮度曲线。
  - 色彩：在曲线之前、线性光下拟合的 3×3 矩阵，加大暗部权重。
  - 上限检验：用 25³ 的 3D LUT 估计*任何*全局色彩/色调映射所能达到的上限。
- 「低频」指先对两张图做高斯模糊（σ = 2 像素）再比较。这样可以去掉锐化、降噪、去马赛克的差异，只保留色调和色彩。

## 3. 结果

### 3.1 逐步结果（样本 e）

| 处理流程 | 像素级 ΔE（平均 / p95） | 低频 σ2 ΔE（平均 / p95） |
|---|---|---|
| LibRaw 直接渲染 | 13.99 / 31.88 | 12.62 / 30.98 |
| + 镜头几何校正 | 11.33 / 27.10 | 10.60 / 26.39 |
| + 色调曲线（不含暗角） | 3.65 / 9.01 | — |
| + 暗角 + 色调曲线 | 3.21 / 7.70 | — |
| + 3×3 色彩矩阵（「模型 A」） | 3.20 / 8.92 | **1.80 / 4.79**（σ6：1.50 / 3.80） |
| 3D LUT：左半幅拟合，右半幅测试 | 3.09 / 8.87 | 2.55 / 7.90 |
| 3D LUT：整幅拟合（全局映射所能达到的最好结果） | 2.16 / 6.12 | — |
| *参照：机内 JPEG 与 NX Studio* | *1.29 / 3.20* | ***0.58 / 1.18*** |
| *参照：NEF 内嵌预览与 NX Studio* | *1.39 / 3.47* | ***0.66 / 1.42*** |

除 LUT 留出测试那一行外，模型结果都是**样本内**的，即在被测的同一张图上拟合。实际使用中的一致性会更差。

### 3.2 各部分的影响

- **色调差距最大。** NX Studio 默认渲染的中间调比线性的相机白平衡渲染亮得多。拟合出的亮度映射（线性输入 → 线性输出）：

  | 输入 | 输出 |
  |---|---|
  | 0.10 | 0.26 |
  | 0.18 | 0.48 |
  | 0.30 | 0.70 |

  更亮的部分开始压缩高光。这里混合了优化校准色调曲线、尼康的基准曝光和动态 D-Lighting，一张图无法把它们分开。
- **这支镜头的几何校正幅度很大。** NX Studio 的自动畸变校正把画面放大 1.063 倍，并做了较强的桶形校正（k1 ≈ −0.28，k2 ≈ +0.15）。边缘位移在半尺寸下最多约 115 像素，全尺寸约 230 像素。
- **暗角校正很强。** 相对中心的增益：

  | 归一化半径 | 增益 | 约合 EV |
  |---|---|---|
  | 0.43 | 1.09 | |
  | 0.62 | 1.24 | |
  | 0.83 | 1.40 | |
  | 0.93 | 1.64 | 四角约 +0.7 EV |

- **色调之后，色彩只是小的一步。** 3×3 矩阵除蓝色那一行外接近单位矩阵。剩下的色彩差异大多不是一个简单矩阵能描述的。
- **剩下的像素级差距主要来自细节，而不是色彩。** ΔE 热图集中在边缘和纹理上，也就是锐化、降噪和去马赛克。模糊后，模型 A 从 3.20 降到 1.80。即使是最好的全局 3D LUT，像素级也停在 2.16。
- **NX Studio 的曝光滑块不是线性增益。**

  | 对比 | ΔE（平均 / p95） |
  |---|---|
  | NX Studio +1 EV 与 NX Studio 0 EV × 2（线性） | 4.31 / 8.59 |
  | 模型 A 乘 2 倍线性增益，与 NX Studio +1 EV | 5.43 / 14.14 |

  实测 NX 的响应（输出亮度，0 EV → +1 EV）：

  | 0 EV | +1 EV |
  |---|---|
  | 0.18 | 0.41 |
  | 0.50 | 0.77 |
  | 0.90 | 0.97 |

  NX Studio 会压缩高光。要模仿它的曝光行为，需要它的曲线模型，而不只是一个增益。
- **NEF 本身就带有一份尼康渲染。** 内嵌预览是全尺寸 5568×3712 的 JPEG（约 2.1 MB），与 NX Studio 导出的差距只有 ΔE 0.66（低频）。

## 4. Q-016 的结论

1. **用 LibRaw 加自建流程，无法做到与 NX Studio 像素级一致。** 尼康自家的两个引擎（相机和 NX Studio）之间的低频差异只有 ΔE ≈ 0.5–0.6。本文最好的全局模型在样本内为 ≈1.5–1.8，样本外会更差。
2. **「肉眼接近」是可以做到的。** 前提是 NICE 按影响从大到小依次模拟：
   1. 默认色调（优化校准曲线 + 基准曝光 + 动态 D-Lighting）
   2. 镜头畸变
   3. 暗角
   4. 按优化校准类型区分的色彩
   5. 接近尼康的锐化与降噪
3. **「NX Studio 可还原」只能指参数，不能指像素。** 这个标注对 L1 参数是准确的，但不能承诺 NX Studio 显示的画面与 NICE 相同。
4. **内嵌预览是现成的、尼康准确的未编辑照片画面。** 它可以用于浏览页和作为对照。但也带来防抖动风险：未编辑的照片进入编辑页、换成 NICE 自己的渲染时，观感会突然改变（见第 5 节）。

## 5. 影响与选项（供决策，尚未决定）

| 选项 | 一致程度 | 成本 / 风险 |
|---|---|---|
| A. NICE 自己的风格：LibRaw + 自建流程，不承诺一致 | 低（默认与 NX 的 ΔE 远大于 5） | 最简单；用户看到的默认效果与 NX Studio 和机内 JPEG 不同 |
| B. 接近尼康的默认效果：LibRaw + 镜头校正 + 按机型 / 优化校准类型标定的色调与色彩 + 近似的动态 D-Lighting | 肉眼接近（目标：低频 ΔE 平均 ≤ 2、p95 ≤ 5） | 需要按机型和类型准备标定数据；需要镜头校正数据（见下文）；永远不会完全一致 |
| C. 用尼康 SDK 渲染（如果许可允许） | 可能完全一致 | 取决于尼康 SDK 的可得性、条款和平台（Q-004）；依赖厂商 |

建议：按 **B** 规划，在 Q-004 中继续调查 **C**，产品措辞按结论 3。

浏览页与编辑页观感不一致是另一个界面问题，需要负责人决定。两种做法：

- 始终显示 NICE 的渲染：前后一致，但与尼康不完全相同；
- 编辑前显示内嵌预览：更快、和尼康一致，但第一次编辑时观感会变化。

镜头校正数据：上面的系数只是从一张图拟合出来的，实际实现需要真实的逐镜头数据。可能的来源（均未验证）：

- NEF 厂商注释中存储的校正数据（Z 卡口机身会写入，用于机内校正）；
- lensfun 数据库；
- NICE 自行标定。

## 6. 本研究的局限

- 只有一个场景、一支镜头、一台相机、一种优化校准（自动）。除 LUT 留出测试外，模型都在被测的同一张图上拟合。
- 标准答案是 8 位 sRGB JPEG；比较在半分辨率下进行。
- 没有分开优化校准曲线、基准曝光和动态 D-Lighting 各自的影响。

## 7. 下一步测试（负责人，NX Studio）

每项都用同一张 NEF、导出 JPEG、只改一处：

1. 动态 D-Lighting **关闭**：把动态 D-Lighting 和优化校准曲线分开。
2. 镜头校正（畸变、暗角）**关闭**：验证几何和暗角模型。
3. 优化校准分别设为**标准**、**中性**、**平面**：得到各类型的色调与色彩，同时服务 Q-017。
4. 换一个不同的场景，最好有色卡或色彩丰富的主体：做样本外检验。
