Last updated: 2026-10-23.

## Phase 0 · Technical validation before development

1. NEF decoding and licensing (Q-004).
2. `.nksc` read/write prototype, reopened in NX Studio (Q-002, Q-003).
3. Rating / keyword interoperability with NX Studio (Q-005, Q-006).
4. Technology stack selection (Q-001).

## v1 · P0

See [product.md](product.md) for requirement IDs and details.

- **Global:** stable shell, two themes, three view modes + fullscreen, floating controls, filmstrip and expanded grid, export dialog, zoom.
- **Browse:** import, sources (folders / albums), album management and classification, filters and sorting, photo information, ratings / color labels / rejection.
- **Edit:** style presets, film profiles, parameter card, histogram and clipping warnings, adjustments ①–⑤ including white-balance presets / eyedropper / Picture Control, grids, negative conversion.
- **Album:** page thumbnails, spread editing, available photos, templates (start with three built-in options), caption editing, finished size, guides, preflight, export print files.
- **Print:** layouts, ID photos (specifications, portrait alignment, full-sheet layout), printers and PDF, color management, soft proofing.

## v1.x · P1

- **Global:** complete Settings preferences, Tab / F / Esc shortcuts, operating-system edge-reveal conflict handling.
- **Browse:** two-photo comparison, IPTC metadata editing.
- **Edit:** My presets, Reset all, history and snapshots, spot removal / local retouching.
- **Album:** complete template library (about 40 page templates / 3–4 collections), template editor, template import/export, print-provider presets.
- **Print:** digital ID photo export, background replacement with local portrait segmentation.

## Later

- Slideshows: an Album Presentation view with title / ending cards, background music, and video export.
- Editing workflow templates and photo status (Q-012).
- Custom Picture Control NP3 export (Q-007).
